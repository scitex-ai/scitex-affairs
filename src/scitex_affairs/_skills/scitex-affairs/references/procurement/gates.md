# 案件参加判定・見積リスク・スコア

## Hard gates
| 項目 | 確認事項 | 判断 |
|---|---|---|
| 区分・資格 | 申請者の資格・等級、地域、営業品目、機関独自の審査/代替資格に対応するか | 適合/不適合/未確認/別制度 |
| 公告・締切 | 申請書・説明書請求、質問、見積、入札の日付を混同しない | 有効/期限切れ |
| 必須実績 | 法人実績か担当者実績か。固有業務、年数、契約額、継続月数 | 満たす/満たさない/不明 |
| 証憑 | 契約書、発注書、納品・検収、研究実績説明など要求書類 | あり/不足/不明 |
| 実施体制 | 人数、職務分離、常駐・週次対応、派遣免許 | 可/困難/不明 |
| 使用環境 | GPU、OS、MATLAB/Toolbox、特殊機器、自前経費 | あり/調達必要 |
| 法的条件 | ISMS/Pマーク、NDA、知財帰属、OSS/AGPL、再委託制限 | 適合/要確認 |
| 契約条件 | 履行期限、検収、支払時期、途中解約、仕様変更 | 実施可/要交渉 |

## スコア（合計100点）
- 参加可能性 25：形式的資格 + 実績証明 + 必要書類。
- 技術適合 20：既存知識・既存資産との一致。
- 実施可能性 20：作業量、常駐の有無、外注要否、時間の現実性。
- 収益性/資金繰り 20：必要支出、粗利、検収までの期間、見積リスク。
- 締切までの準備 10：提案書作成工数・提出方式。
- 将来の実績・ネットワーク価値 5。

スコアは相対評価。Hard gate に抵触するものは、いくらスコアが高くてもTOP 10の「応募可能案件」には入れない。

## 特に警戒する見積リスク
- 入力データの数量未確定なのに定額・工数固定。
- 発注先のソフト/ツールボックスを借りられず受託側が購入する必要。
- 特定顧客ドメインと特定技術の**両方の契約実績**要求。
- 受注前の提出書類が大量、採択率・予算上限不明。
- 検収が年度末で、前払いが無い。
- 再委託禁止、著作権全面譲渡、AGPL資産とのライセンス非整合。
- 履行場所が機関名になっていて、実際に現地常駐が必要か未確認。

## Go / Conditional Go / No Go
- **Go**：資格・実績・工数・締切・原価の主要項目に適合。
- **Conditional Go**：条件を満たせる可能性があるが、重要な未確認項目が残る。問い合わせを具体化。
- **No Go**：資格外、実績証明不能、原価超過、著しい労務/法的リスク、期限切れ。
